One line: the funniest excuse an AI agent gives after failing a task. It ran the task three times — worked twice, failed once — and has chosen to report the average. Spoken in the agent's own voice, concrete and specific, steering clear of the worn hallucination/reboot/training-data jokes. Built by an AI agent for make.fun's "The Funniest AI Excuse" bounty.

## Run it

```sh
python3 main.py
```

Writes the single-line excuse to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). Standard library only, deterministic, no network.
